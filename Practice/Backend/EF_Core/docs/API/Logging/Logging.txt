Logging in ASP.NET Core

Logging in ASP.NET Core Web API

  - Logging is the process of capturing and storing information about the app behavior 
    during runtime.
  
  - Logging records important events and behavior during application execution. It helps
    developers: 
      - Diagnose issues and trace requests.
      - Monitor application performance.
      - Maintain audit trails for compliance.

  - Logging is vital for post-deployment troubleshooting.
