

Basic Authentication

 - Create a new handler for Basic Authentication
 - Register in Program.cs
 - Use [Authorize] annotation new every endpoint you wish to protect
 - In Postman:
      Add a new value in the request Header
        Key:Authorize value: Basic followed by the encoded Base64 formatted code.







Encode email and password separated by a colon, using Base64 format
