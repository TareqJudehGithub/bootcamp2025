Language Integrated Query (LINQ)



 (LINQ) is a powerful .NET feature that embeds data querying capabilities directly into C# (and VB.NET), providing a consistent syntax for filtering, ordering, and transforming data from various sources like in-memory collections, SQL databases, and XML. It eliminates the need for managing different languages for each data source by offering a unified, strongly-typed API

 LINQ allows a simple, efficient, and unified way of querying over different types of data.

 Queries execute only when the result is needed.

 Code written with LINQ is cleaner, more readable and shorter.
 


 Setting up LINQ in EF Core

 In the .Program.cs under Console project:
 
  using EntityFrameworkCore.Data;

  // Create new instance of context - FootballLeagueDbContext
  var context = new FootballLeagueDbContext();

  // Select * from Teams

  // Look at the Teams, convert it to List, then we can start querying.
  var teams = context.Teams.ToList();
